# Sport

Suivi de programmes de musculation : splits, séances, chrono de repos, stats.
Web app installable (PWA), sans serveur : les données restent dans le navigateur.

En ligne : https://nnd202.github.io/Sport/

Le dépôt est public : il ne contient que le code et un programme de démonstration inventé.

- `node tools/check.mjs` : liste CORE du service worker et tests du moteur.
